# Dev Portfolio

This is a simple developer portfolio website.

## Project Structure

- `index.html`: The main HTML file for the website.
- `style.css`: The main CSS file for styling the website.
- `all.css`: An additional CSS file (currently empty).
- `note.txt`: A text file with some git commands.
- `.gitignore`: A file to specify untracked files to ignore.
- `README.md`: This file.

## How to Run

1. Clone the repository.
2. Open `index.html` in your web browser.

## Technologies Used

- HTML
- CSS (with Google Fonts)
